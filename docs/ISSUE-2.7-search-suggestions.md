# Issue 2.7: 搜索实时联想

## 描述

搜索框输入时，防抖 300ms 后从知识库 Markdown 文件的**标题**中匹配，下拉浮层显示前 5 条建议。

## 验收标准

- [ ] 输入框输入时，300ms 防抖后才触发联想请求
- [ ] 请求 `/api/search?q=xxx&title_only=1`（或前端从返回结果中提取标题）匹配文件标题
- [ ] 联想浮层在搜索框下方出现，带轻微阴影和圆角
- [ ] 浮层最多显示 5 条，每条显示文件名 + 分类 badge
- [ ] 键盘 ↑↓ 可选择条目，Enter 确认执行搜索
- [ ] 浮层外点击 / Escape 关闭浮层
- [ ] 搜索框失焦时浮层消失（延迟 200ms 以便点击选中条目）
- [ ] 输入为空时浮层不显示
- [ ] 浮层带入场微动画（opacity + translateY）
- [ ] 联想列表 item hover 有高亮
- [ ] 可点击联想 item 直接执行搜索

## 后端变更

- 当前 `/api/search` 返回所有匹配内容（含 snippet）
- 此功能**不需要后端变更**：直接使用现有 `/api/search?q=xxx`，前端从结果中提取标题匹配即可
- **优化方案**：如果搜索慢，可考虑加 `limit=5` 参数（后端可选）
