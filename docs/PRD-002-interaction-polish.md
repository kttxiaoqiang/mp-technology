# PRD-002: 交互动效与搜索建议增强

## 版本

v1.0 | 2026-05-29 | 张经理

---

## 1. 概述

在 kb-web v1（Apple/Stripe 明亮高级风格重构）的基础上，对前端交互体验进行全面升级，打造具有"科技感"和"高级感"的流畅交互体验。

## 2. 目标

- **科技感**：微动效、发光滚动条、实时联想
- **高级感**：丝滑过渡、按压反馈、入场动画
- **实用性**：搜索实时联想减少用户输入成本

## 3. 特性列表（按优先级）

### P0 — 核心交互增强

| # | 特性 | 说明 |
|---|------|------|
| F1 | 点击按压反馈 | 卡片/按钮 `:active` 时 `scale(0.97)`，按钮 Ripple 水波纹效果 |
| F2 | 卡片入场动画 | 分类卡片、文件卡片、搜索结果列表依次淡入（staggered fade-in, 间隔 50ms） |
| F3 | 滚动条美化 | 细条（5px）+ hover 时 `box-shadow` 发光，滚动轨道透明 |
| F4 | 交互过渡全面审计 | 确保所有可交互元素（tab, badge, file-row, pagination）都有 `transition` |

### P1 — 视觉强化

| # | 特性 | 说明 |
|---|------|------|
| F5 | Hover 强化 | 卡片 hover 时图标放大 1.1x、边框 `box-shadow` 发光效果 |
| F6 | 按钮 Ripple | 所有 `.btn` 点击时产生水波纹扩散动画 |

### P2 — 智能搜索

| # | 特性 | 说明 |
|---|------|------|
| F7 | 搜索实时联想 | 输入时防抖（300ms），从 Markdown 文件标题中匹配，下拉浮层显示前 5 条建议 |

## 4. 非目标（明确排除）

- ❌ 毛玻璃卡片效果（破坏明亮干净感）
- ❌ 页面级路由过渡动画（涉及 SPA 架构变动，收益/成本比低）
- ❌ 暗色模式（当前只有亮色）
- ❌ 后端搜索算法改动（仅前端联想 UI）

## 5. 设计原则

- **Subtle 优先**：动效时长 150-300ms，缓动函数用 `cubic-bezier(0.3, 0, 0.4, 1)`
- **不牺牲性能**：只用 CSS transform/opacity（GPU 加速），不动布局属性做动画
- **渐进增强**：无 JS 动效库依赖，纯 CSS + 少量原生 JS
- **一致性**：所有动效风格统一，使用相同缓动曲线

## 6. 技术约束

- 纯 CSS + 原生 JS，无第三方库
- 修改范围限于 `/home/zhang/kb-web/public/index.html`（内联 CSS + 内联 JS）
- 保持 SPA 架构不变（hash-based routing）
- 保持与现有后端 API 兼容

## 7. 验收标准

1. 所有卡片/按钮点击有按压缩放反馈（`:active` 状态 < 200ms）
2. 页面加载时分类卡片依次淡入（间隔 50ms），文件列表同样
3. 滚动条为 5px 细条，hover 时微发光
4. 所有 `.btn`, `.tab`, `.badge`, `tr`, `.faq-item`, `.search-result-item` 均有 `transition`
5. 卡片 hover 时图标放大、边框发光
6. 按钮点击有水波纹扩散效果
7. 搜索框输入后 300ms 防抖，出现联想浮层，支持键盘选择

## 附录：交互原型速写

```
入场动画:
  页面加载 → [卡片1]→50ms→[卡片2]→50ms→[卡片3]→...
  
点击反馈:
  [卡片] → :active → scale(0.97) → 释放 → scale(1.0)
  
搜索联想:
  输入"密" → 防抖300ms → fetch(/api/search?q=密&title=1) → 浮层显示
  
滚动条:
  ::-webkit-scrollbar-thumb:hover → box-shadow: 0 0 8px var(--primary)
```
